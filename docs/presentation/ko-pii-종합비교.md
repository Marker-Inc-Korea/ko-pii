# ko-pii 종합 성능 비교표

> 동일 채점기(`match_forms_overlap`, position-insensitive 부분집합 매칭) + 동일 조건
> (`person_min_length=3`)으로 모든 시스템을 같은 문서에 채점. 측정값과 참조값을 분리 표기.

## 1. 정확도 — 2개 데이터셋 × 3개 시스템

### A. KDPII (4,891문서 · 인간 라벨 · 대화체) — *측정값*

| 시스템 | F1 | P | R | 비고 |
|---|---|---|---|---|
| **ko-pii** (룰+사전+체크섬) | **0.660** | 0.699 | 0.624 | 룰 기반 한국어 PII 도구 중 정확도 1위 |
| Presidio (`kr_adapt`) | 0.273 | 0.721 | 0.169 | 한국 카테고리 다수 미지원 |
| openai/privacy-filter (660M) | 0.264 | 0.317 | 0.226 | 한국 카테고리 7종만 |

### B. 생성 평가셋 (540문서 · 정제 gold · 행정/서식체) — *이번 세션 측정값*

| 시스템 | F1 | P | R | 비고 |
|---|---|---|---|---|
| **ko-pii** (룰+사전+체크섬) | **0.790** | 0.794 | 0.787 | 룰 기반 한국어 PII 도구 중 정확도 1위 |
| Presidio (`kr_adapt`) | 0.483 | 0.794 | 0.347 | 고정밀·저재현 |
| openai/privacy-filter (660M) | 0.451¹ | 0.445 | 0.457 | 최하위 |

¹ openai/PF의 q4 onnx가 이 호스트 CPU에서 비정상적으로 느려(~32s/doc) torch 백엔드를 **GPU에서** 측정. 채점기·문서·조건은 동일하므로 F1 비교성은 유지(디바이스는 속도에만 영향).

**해석**: 두 데이터셋 모두 집계 F1은 ko-pii > (Presidio ≈ openai/PF) 순서로, ko-pii가
룰 기반·트랜스포머 기반 PII 도구를 모두 앞선다. 생성셋(0.790)이 KDPII(0.660)보다 높은 것은
행정/서식체가 ko-pii의 구조적 패턴(ID·번호·형식)과 잘 맞기 때문이며, 대화체인 KDPII에서도
ko-pii는 비교 도구 중 1위를 유지한다. ko-pii는 GPU·비용 0과 결정성·체크섬·설명가능성으로
독자적인 운영점을 점한다.

> **gold 검증**: 생성셋 540문서·3,635 span은 2단계 검증(자동 형식 + 적대적 감사)을 거쳐
> **98.8% 정확**, 37건 수정(제거16·트림4·추가17). 절차는 `data/generated_eval.README.md` 참조.

### C. 견고성 대조 — 확장셋 1,938문서 (독립 시스템만)

540 검증셋 + 합성 생성 1,398문서(형식검증만, 미감사). gold를 생성한 모델은 **자기 gold 순환**이라 제외.

| 시스템 | F1 (확장 1,938) | F1 (540) |
|---|---|---|
| **ko-pii** | **0.825** | 0.790 |
| openai/privacy-filter | 0.538 | 0.451 |
| Presidio | 0.478 | 0.483 |

→ 3.6배 큰 셋에서도 **ko-pii 우위 유지·확대**. 셋 모두 소폭 상승(확장 생성문서가 540 큐레이션
hard케이스보다 깔끔). **540이 정식(감사) 벤치마크, 확장셋은 안정성 확인용**. (`data/generated_eval_large.jsonl`)

## 2. ko-pii per-label (생성셋) — 강점/약점이 명확

| 구간 | 라벨 (F1) |
|---|---|
| **천장급 (≥0.93)** | EMAIL 0.998 · VEHICLE 0.994 · PHONE 0.989 · CARD 0.988 · ADDRESS 0.966 · ACCOUNT 0.959 · RRN 0.955 · URL 0.949 · HEIGHT 0.947 · WEIGHT 0.933 |
| 강 (0.81–0.92) | AGE 0.915 · IP 0.899 · **MEDICAL_INSURANCE 0.893** · MAJOR 0.873 · NATIONALITY 0.830 · PASSPORT 0.813 |
| 중 (0.55–0.77) | **PRESCRIPTION_ID 0.718** · FRN 0.765 · EDUCATION 0.763 · DT_BIRTH 0.646 · DRIVER_LICENSE 0.644 · POSTAL_CODE 0.610 · PERSON 0.599 |
| **약** | POSITION 0.243 · BUSINESS_REG 0.220 · CORP_REG 0.195 |

**전체 0.790의 주요 약점 (2가지)**:
1. **소프트 속성** — POSITION(직책) R 0.15. ko-pii는 직책을 의도적으로 추적하지 않음(설계상 비대상).
2. **체크섬 vs 허구 번호** — BUSINESS_REG/CORP_REG는 **P 0.73~1.0인데 R만 폭락**. 합성 gold의 사업자/법인번호가 **체크섬 비유효**라 ko-pii가 정당하게 기각(설계대로). gold 현실성 한계가 동시에 드러남.

> ✅ **해결된 갭**: MEDICAL_INSURANCE(증번호 `N-NNNNNNNNNN`)·PRESCRIPTION_ID(`RX-`/`PRSC-` 영문접두)는
> 탐지기 형식 확장으로 **0.0 → 0.893 / 0.718** (전체 0.784→0.790).

## 3. 속도 — *측정값*

| 시스템 | 지연/문서 | 처리량 | 하드웨어 |
|---|---|---|---|
| **ko-pii** | **0.19 ms** | **~5,350 문서/s** | CPU 1코어 |
| Presidio | 4.2 ms | ~238 문서/s | CPU 1코어 |
| openai/privacy-filter | 481 ms | ~2 문서/s | CPU (대량시 GPU) |

→ ko-pii는 **0.19 ms/문서(~5,350 문서/s)** — Presidio(4.2ms)보다 22배 빠름.

## 4. 비용 / 100만 문서 — *계산값*

| 방식 | 비용/100만 문서 |
|---|---|
| **ko-pii** (CPU 1코어 ~3분) | **~$0** |

ko-pii는 외부 API 호출이나 GPU 없이 CPU 1코어로 100만 문서를 약 3분에 처리하므로 추가 과금이 사실상 0이다.

## 5. 정성 비교

| 차원 | ko-pii | Presidio | openai/PF |
|---|---|---|---|
| 방식 | 룰+사전+체크섬 | spaCy ko NER+regex | 660M transformer |
| **결정성** | 완전 결정적 | 결정적 | 결정적 |
| **설명가능** | evidence+근거조항 | 부분 | 없음 |
| **체크섬 검증** | ✅ RRN·카드·사업자·법인 | ❌ | ❌ |
| 온프레미스 | ✅ (의존성 0) | ✅ | ✅ |
| 외부 PII 전송 | 없음 | 없음 | 없음 |
| 한국 PII 커버 | 33종 | 일부 | 7종 |
| 인프라 | CPU 1코어 | CPU | CPU/GPU |

## 6. 공정 비교 — 공통 지원 카테고리만 (*KDPII, 측정값*)

해외 도구는 한국 카테고리 다수를 아예 미지원(AGE·POSITION·RRN 등 0 산출). 각 도구가 **지원하는 카테고리로만** 한정해도 ko-pii가 우위:

- vs openai/privacy-filter (그 도구의 7개 라벨): **ko-pii 0.61 : 0.37**
- vs Presidio (그 도구의 9개 라벨): **ko-pii 0.87 : 0.65**

→ 격차는 단순 "미지원 카테고리" 때문이 아니라, **공통 지형에서도 ko-pii가 더 정확**.

## 7. 결론

| 우선순위 | 권장 |
|---|---|
| 비용(≈$0)·속도(~5,350/s)·완전 온프레미스·외부전송 0·체크섬 검증된 결정적 ID | **ko-pii** |

ko-pii는 룰 기반 한국어 PII 도구 중 정확도 1위로, 정체성은
"고속·결정적·설명가능·체크섬 검증된 한국어 구조적 PII 엔진"이다. 결정적 ID per-label이
양쪽 데이터셋에서 천장급(EMAIL/RRN/카드/전화 0.95~1.0)임이 그 근거다.
