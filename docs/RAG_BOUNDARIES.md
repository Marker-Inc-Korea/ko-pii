# RAG 연동의 처리 범위

1.22.2부터 LangChain과 LlamaIndex 어댑터는 본문과 metadata의 JSON 문자열 값을
같은 Anonymizer/Vault로 처리합니다. 입력 객체는 복사하며 문서 ID, score와 관계 등
프레임워크 필드를 유지합니다. 원본 검색 노드를 다음 질의에 재사용해도 가명화된
토큰이 원본에 덮어써지지 않습니다.

metadata는 제한된 깊이/크기의 JSON 객체여야 합니다. 임의 Python 객체는 오류로
거부합니다. 키는 프레임워크의 제외 목록을 유지하기 위해 보존하지만, 현재 정책상
마스킹해야 하는 개인정보가 키에서 탐지되면 오류로 거부합니다. 일반 숫자 값은
자동으로 식별자로 판단하지 않으므로 식별번호는 문자열로 전달하거나 별도로 처리하세요.

LangChain은 str, Document, 이들의 list/tuple만 받습니다. `{"context": ...}` 같은
dict를 체인 전체에서 바로 넘기면 TypeError입니다. 마스킹할 필드를 먼저 선택하세요.
LlamaIndex는 text 노드만 지원하며 이미지 등 미지원 노드는 오류로 거부합니다.
`include=[]`도 코어처럼 오류이며 필터를 생략하려면 None을 사용합니다.

처리 결과는 여전히 선택한 mode/include/exclude/strategy와 탐지 성능에 종속됩니다.
REVIEW/ALLOW와 미탐은 원문이 남을 수 있습니다. 메타데이터 정수, 문서 ID, 사용자 질의,
프롬프트 템플릿, 모델의 응답, 다른 체인 가지를 이 어댑터가 포괄적으로 보호하지 않습니다.
본 도구는 네트워크 차단기나 모델 공급자의 학습/보관 설정 관리자가 아닙니다.

호출마다 임시 Vault를 새로 만들면 토큰 번호도 별도 범위를 가집니다. 여러 호출의
결과를 합치거나 복원하려면 같은 Vault를 명시적으로 제공하고 출력과 안전하게 분리하세요.
외부에서 이미 토큰화된 문서를 다른 Vault와 섞지 마세요. 실패 호출의 사용자 제공
Vault 전체를 롤백하는 트랜잭션도 제공하지 않습니다.
