# 1.23.1 금융 필드와 정규식 비용 재검사

2026-11-18, Python 3.12.3. 코어 규칙 기반 경로를 실제 PyPI 1.23.0과 비교했습니다.
모델·외부 서비스·사용자 규칙은 추가하지 않았으며 실제 고객 업무 승인 자료가 아닙니다.

## 수정과 회귀 검사

- 값 없는 계좌 키워드 뒤 공백을 여러 선택적 구간으로 다시 나누던 정규식 역추적을
  제거했습니다. 은행 앞/뒤 탐지에서 기존 구간 전체를 선형 순회하던 중복 검사도
  정렬된 비겹침 구간의 이진 조회로 바꿨습니다. 독립 순회 oracle과 생성형 입력으로 대조합니다.
- 계좌 필드의 등호·인용부호·괄호, 번호 뒤 쉼표와 은행명을 인식합니다. 숫자 원문 좌표,
  바깥 구분자와 Vault 저장 단위를 유지하며 일반 단어 속 짧은 은행 별칭을 거부합니다.
  명칭이 붙어 쓰인 한글 문장과 한정된 조사, 기존 별칭·결합 표기도 함께 검사합니다.
- 카드의 미지원 긴 연결 묶음에서 유효한 일부만 잘라 탐지하지 않습니다. 기존 길이·
  형식·접두사·Luhn 조건을 유지하고 다른 긴 숫자 필드는 공백만으로 합치지 않습니다.
  [짧은 숫자 필드의 모호성과 출력 변화](../docs/IDENTIFIER_VALIDATION.md)를 확인하세요.
- 새로운 금융 경계 135개 회귀 사례에서 기존 설치본은 93개 실패/42개 통과, 새 구현은
  모두 통과했습니다. 표기·Unicode·메타데이터 검사가 포함돼 있으며 독립 결함 개수나
  운영 정확도를 뜻하지 않습니다. API·JSON·CLI·Vault·AUDIT와 정상 숫자 필드도 함께 검사합니다.
- 소스 전체 3,905개 통과/15개 생략, 별도 wheel 설치 3,890개 통과/30개 생략입니다.
  생략은 선택 의존성으로 인한 것이며 성공으로 계산하지 않습니다. 같은 검사의 반복을
  합산하지 않습니다. 문서의 Python·텍스트 CLI·JSON CLI 예제도 통과했습니다.
- 설치 wheel의 선택 RAG/MCP 경로 33개 및 최소 MCP 1.28.1/2.0.0 stdio 각 19개를
  통과했습니다. 새 따옴표 계좌의 실제 요청·응답·Vault 복원도 포함합니다.
  전체 154개 소스 파일 타입 검사와 린트도 통과했습니다.

## 비용 재현

아래는 같은 호스트의 `time.process_time()` 단발 측정이며 서비스 지연이나 처리량 보증이 아닙니다.
가져오기 비용을 제외한 직접 탐지 시간을 측정했고 별도 프로세스로 느린 구버전을 제한했습니다.

- 1.23.0의 `계좌` 뒤 공백 128/256/512개에서 CPU 약 0.0059/0.0450/0.3468초였습니다.
  입력을 두 배 늘릴 때 약 여덟 배 증가했습니다. 새 경로는 공백 100,000개에서 직접 탐지
  약 0.023초, 전체 Anonymizer 약 0.27초로 끝났습니다. 다른 입력의 무조건적 시간 상한은 아닙니다.
- 은행 계좌 1,000/4,000건은 기존 약 0.0339/0.4866초, 새 경로 약 0.0081/0.0351초입니다.
  기존 후보 수에 비례하던 중복 비교를 제거한 영향입니다. 정상 출력 건수는 동일합니다.
- 긴 값 없는 필드와 다중 계좌를 성능 회귀 검사에 추가했습니다. 외부 정규식·파일 추출·
  보조 탐지기의 실행 시간까지 제한하는 새 샌드박스나 동시 처리 제어를 추가한 것은 아닙니다.

## 외부 합성 자료 비교

[고정 프로토콜](external-protocol.json)의 K-PII-Bench Track A, CC-BY-4.0을 사용합니다.
리비전·해시·14개 대응 라벨과 STRICT/redact 정책은 이전 기록과 같습니다. 4개 미대응
라벨은 점수 밖이고 upstream 공식 BIO 점수나 실제 발급 번호·고객 문서의 성능이 아닙니다.

0~1999는 이미 관찰한 회귀 자료입니다. 2000~2499는 제품 코드 동결 후 설치 wheel로
확인했습니다. 같은 합성 코퍼스의 다른 순위일 뿐 블라인드·독립 도메인이라고 주장하지 않습니다.
개발 중 후보와 최종 구현을 회귀 자료에 반복 측정했고, 마지막 확인 후 제품 코드는 바꾸지 않았습니다.

| SHA-256 순위 (끝 제외) | 1.23.0 F1 | 1.23.1 F1 | 완전히 치환되지 않은 정답 구간 (전 → 후) |
|---|---:|---:|---:|
| 0~500 | 0.5547 | 0.5593 | 898 → 886 |
| 500~1000 | 0.5428 | 0.5469 | 961 → 950 |
| 1000~1500 | 0.5522 | 0.5549 | 918 → 911 |
| 1500~2000 | 0.5578 | 0.5622 | 951 → 939 |
| 2000~2500 | 0.5548 | 0.5582 | 948 → 939 |

전체 gold 9,598개 중 완전히 치환되지 않은 구간은 4,676 → 4,625개로 51개 감소했습니다.
변화는 모두 ACCOUNT입니다. 새 strict FN/FP와 이전에 치환되다가 새로 남은 gold는 각 0개,
해소 FN과 추가 완전 치환은 각 51개입니다. 이 표본에서만 관찰한 결과이지 무미탐·무오탐
보증이 아닙니다. CARD 및 자유 문장 PERSON/ADDRESS 성능이 개선됐다는 근거로 쓰지 않습니다.

앞 네 표본의 1.23.0은 배포본과 제품 해시가 같은 소스/설치 wheel의 기존 기록이며,
마지막 표본은 실제 PyPI 설치본으로 새로 실행했습니다. 실제 출력의 잔존에는 정책상
보존·부분 치환도 포함되므로 위 숫자를 개인정보 유출률이라고 해석하면 안 됩니다.

## 재현과 남은 범위

```bash
python scripts/evaluate_external.py --cache /tmp/ko-pii-external \
  --download --rank-start 0 --output /tmp/ko-pii-1.23.1-ranks-0-500.json
python scripts/evaluate_external.py --cache /tmp/ko-pii-external \
  --rank-start 2000 --output /tmp/ko-pii-1.23.1-ranks-2000-2500.json
```

두 버전을 다른 환경에 설치하고 출력 경로를 분리합니다. 500/1000/1500도 같은 방식입니다.
기존 결과는 덮어쓰지 않으며 `--download` 없는 평가에서는 네트워크·모델을 호출하지 않습니다.

- 제품 `.py` 경로/내용 결합 SHA-256 (소스/wheel):
  `6fef560465c2066dd49f7dc9f16f7cdd980dffab822292d4c76cdf1de2250fdd`
- 2000~2500 선택 문서 해시:
  `67475cb5bfc9466cb3d1a5642aa79d1e52d56ccb850061e2cd2941faab73bb70`
- 앞 네 표본 해시는 [1.23.0 기록](RECHECK_1_23_0.md)과 동일합니다.

이 검증으로 실제 업무의 모든 개인정보 제거를 승인하지 않습니다. 자유 문장의 이름·주소,
필수 식별번호의 업무별 재현율, 추출되지 않은 문서 영역과 최종 출력의 과다 마스킹은
[도메인 평가](../docs/DOMAIN_EVALUATION.md)와 실제 업무 자료로 확인해야 합니다.
