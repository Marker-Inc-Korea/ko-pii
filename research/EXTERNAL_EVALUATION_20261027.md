# 여권 형식 수정 후 고정 외부 평가 재검사

2026-10-27, ko-pii 1.22.5 PyPI 설치본(Python 3.12.3)과 1.22.6 수정 소스(Python 3.12.13).

## 수정 근거

1.22.6은 외교부의 차세대 여권번호 예시와 Microsoft Purview 형식 정의에 근거해
숫자/영문 혼합 번호 누락을 수정합니다. 숫자 우회 정규화가 정상 영문 접두사를 지우던
경로도 별도로 재현했습니다. `PP` 같은 문서 종류 코드와 번호 접두사의 혼동을 정정합니다.
근거 링크와 실제 지원 범위는 [패턴 설명](../docs/pattern_analysis.md)에 있습니다.

수정 조건은 외부 표본의 개별 실패 행이 아니라 위 형식 명세와 자체 합성 재현 사례로
정했습니다. 고정 표본의 결과를 보고 패턴을 재조정하지 않았습니다. 이미 측정한 표본이므로
새로운 블라인드 평가나 독립적인 홀드아웃 성공으로 부르지 않습니다.

## 결과

[프로토콜](external-protocol.json), 실행 스크립트, 표본 선정과 데이터 해시가 같습니다.
실고객 문서가 아닌 K-PII-Bench Track A 합성 자료 500건, 14개 대응 라벨, STRICT/redact,
사용자 규칙/제외어/모델 없음, 엄격한 문자 span 매처 조건입니다.

| 지표 | 1.22.5 | 1.22.6 |
|---|---:|---:|
| TP / FP / FN | 1031 / 832 / 846 | 1031 / 832 / 846 |
| Precision / Recall / F1 | 0.5534 / 0.5493 / 0.5513 | 0.5534 / 0.5493 / 0.5513 |
| 완전히 치환되지 않은 gold span | 939 | 939 |
| PASSPORT recall (gold 73개) | 0.479 | 0.479 |

라벨별·도메인별 집계와 출력 잔존 상태도 동일했습니다.
[기계 판독 요약](external-1.22.6-summary.json)에 설정, 환경, 결과와 해시를 기록합니다.
원문과 문서별 결과는 재배포하지 않습니다.

## 해석

이번 회귀 수정이 이 표본의 점수를 높이지는 않았습니다. 따라서 전체 여권 탐지나 실업무
완성도를 입증했다고 주장하지 않습니다. 고정 회귀 검사는 실제 형식 누락을 재발시키지
않기 위한 것이며, 고객 문서에서의 라벨별 미탐·오탐·최종 출력 검증은 여전히 필요합니다.

이전 측정의 [한계와 잔존 상태 해석](EXTERNAL_EVALUATION_20261026.md)도 그대로 적용됩니다.
