# 1.26.1 평가 입력·출력 보고서 경계 재검사

2026-11-18, Python 3.12.3. 탐지·치환 규칙을 바꾸지 않고 평가 API와 기준 보고서의
입력 검사를 보완했습니다. 새 모델·분류기·OCR·외부 호출·런타임 의존성은 없습니다.

## 실제 배포본에서 재현한 문제

설치한 1.26.0에서 다음을 확인했습니다.

- Python `evaluate()`가 알 수 없는 정답 라벨을 조용히 제외했고, 중복 정답은 점수와
  보고서의 집합 행에 다르게 반영됐습니다. bool 좌표·범위 밖 구간과 원문에 맞지 않는
  `GoldSpan.text`도 허용했습니다. JSONL 로더에서 이미 하던 검사가 직접 API에는 빠져 있었습니다.
- 출력 회귀 비교가 `replaced`와 `covered_source_characters: 0`의 모순, 음수·bool 치환
  길이를 받아들였습니다. 정답 span이 없는 음성 문서의 출력 행 누락·추가도 검출하지 못했습니다.
- 기준 JSON의 중복 키·NaN/Infinity·과도한 중첩이 파생 요약 등 비교에서 사용하지 않는
  위치에 있으면 정상 비교로 끝났습니다. 기존 파서가 이를 조용히 허용했습니다.

수정본은 Python 자료 전체를 라벨 선택·탐지 전에 검증하고, 치환 상태와 실제로 덮은
문자 수의 관계·전체 출력 문서 집합·지원 계약을 비교 전에 확인합니다. CLI 기준 보고서는
엄격한 JSON으로 읽으며 잘못된 자료는 종료 코드 2로 거부합니다. 기존 출력 파일을
보존하고 새 정상 비교 보고서를 쓰지 않습니다.

이 검사는 보고서의 구조적 일관성 검사입니다. 악의적인 작성자가 일관성 있게 위조한
결과, 누락된 정답이나 잘못된 정답 의미까지 검증하는 서명·인증 기능은 아닙니다.
파생 요약은 기존처럼 판정 근거로 신뢰하지 않고 문서별 좌표·상태에서 회귀를 계산합니다.

## 검증 근거

- 새 단위 검사 56개를 설치한 1.26.0에 그대로 적용하면 47개 실패/9개 통과입니다.
  입력·상태·CLI 조합 수이며 독립 결함 47개나 정확도 표본 56건이라는 뜻은 아닙니다.
- 같은 단위 검사와 생성형 검사는 수정본에서 57개 모두 통과했습니다. 생성형 검사는
  Unicode와 반복 값·겹친 정답·처리 모드·전략을 바꿔 정상 보고서의 자기 비교를 확인합니다.
- 전체 소스 검사 5,027개 통과/15개 생략, 선택 SDK 설치/미설치의 158개 소스 타입 검사와
  린트가 통과했습니다. 생략은 성공으로 계산하지 않습니다.
- 설치 wheel의 코어-only 환경에서 네트워크 호출을 금지한 API 평가/거부와 정상 텍스트·
  JSON·표·AUDIT·Vault 왕복을 확인했습니다. CLI 성공 및 오류 종료·기존 보고서 보존,
  실제 설치 위치와 제품 코드 해시도 확인했습니다. 호스트 전체의 네트워크 통제는 아닙니다.
- 새 경계 단위 검사는 Windows/macOS 배포 검사 목록에도 포함합니다. 배포 파이프라인은
  wheel·sdist·선택 SDK·문서 예제와 Python 3.10/3.12/3.14를 다시 검사합니다.

제품 Python 158개 파일의 상대 POSIX 경로 순서에 대해 `경로 + NUL + 내용 + NUL`을
결합한 SHA-256은 `b5b63076ebc2523eaff92b764937e7a2c3f8c59e167ea365a01642642e31304d`입니다.
1.26.0 대비 제품 변경 파일은 버전 선언과 `eval/domain.py`, `eval/output.py`뿐입니다.
최종 GitHub Actions와 `distribution-manifest.json`으로 배포 검증·파일 해시를 확인하세요.

## 정상 평가 결과가 유지되는지 확인

[기존 고정 프로토콜](external-protocol.json)의 K-PII-Bench Track A 앞 500건을 재실행했습니다.
같은 CC-BY-4.0 합성 파일·리비전·해시·라벨 대응·STRICT/redact 조건입니다. 이미 본
회귀 자료이며 새 블라인드 평가나 고객 문서 검증이 아닙니다.

| 지표 | 1.26.0 | 1.26.1 |
|---|---:|---:|
| strict TP / FP / FN | 1,052 / 833 / 825 | 1,052 / 833 / 825 |
| micro F1 | 0.559277 | 0.559277 |
| 완전히 치환되지 않은 gold 구간 | 886 | 886 |

문서·라벨·좌표별 새/해소 FN·FP와 출력 상태 변화는 모두 0개입니다. 이 잔존 집계에는
정책상 보존·부분 치환이 포함되므로 유출률이 아닙니다. 나머지 기존 2,500건을 이번에
다시 실행한 것으로 주장하지 않으며 과거 값은 [1.26.0 기록](RECHECK_1_26_0.md)에 있습니다.

```bash
python scripts/evaluate_external.py --cache /tmp/ko-pii-external \
  --rank-start 0 --output /tmp/ko-pii-1.26.1-ranks-0.json
```

최초 다운로드에만 `--download`가 필요합니다. 다른 버전 결과는 덮어쓰지 말고 별도 경로에
저장합니다. 정상 평가 예제와 전환 조건은 [도메인 평가](../docs/DOMAIN_EVALUATION.md)를 참고하세요.

## 사업 적용 판단에서 남은 사항

이 패치는 잘못된 평가 입력과 모순된 보고서가 정상 비교로 사용될 가능성을 줄입니다.
고객의 실제 문서, 필수 라벨, 허용 미탐·과다 마스킹 기준과 승인 주체는 아직 확정·검증하지
않았습니다. 패키지·배포 검사가 통과해도 그 업무의 적용 완료나 법적 익명성 승인을 뜻하지 않습니다.
