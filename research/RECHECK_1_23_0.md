# 1.23.0 한국어 기록 경계와 겹침 치환 재검사

2026-11-18. 코어 규칙 기반 경로를 실제 PyPI 1.22.18과 비교했습니다.
모델·사용자 제외어·추가 탐지기를 넣지 않았습니다. 이 기록은 고객 업무 승인이나
전체 개인정보 제거 보증이 아닙니다.

## 수정과 동작 검사

- 이름 필드의 Unicode 줄 경계·빈 줄·인용부호, 명시적 사람 역할의 서술격 표현,
  상세주소의 쉼표·괄호·숫자 골목길을 수정했습니다. NFC/NFD의 실제 원문 좌표,
  제외어와 AUDIT, 일반 문구·팀·회사·다음 기록을 잘못 가리지 않는 경계를 함께 검사합니다.
- 고위험 후보와 겹쳐 버려진 완전 치환 후보의 나머지를 파생 보호 구간으로 처리합니다.
  선택된 BLOCK 라벨·전략과 병합의 후보 적격성을 유지하며, 부분 마스킹을 강제로
  완전 치환으로 바꾸지 않습니다. [처리 단위와 호환성](../docs/SCOPED_RULES_AND_TRACE.md)을 참고하세요.
- 기존 PyPI 설치본에서 이름/주소/공개 처리 경로의 217개 새 회귀 사례 중 176개 실패,
  41개 통과를 확인했습니다. 새 구현에서는 모두 통과합니다. 이는 경계 변형이 포함된
  사례 수이지 176개의 독립 결함이나 정확도 평가 표본을 뜻하지 않습니다.
- 최종 소스는 3,762개 통과, 14개 생략입니다. 별도 wheel 설치는 3,748개 통과,
  28개 생략이며 문서의 Python·텍스트 CLI·JSON CLI 예제도 통과했습니다.
  연구 코퍼스가 없는 sdist 자산만으로는 3,738개 통과, 38개 생략했고 같은 문서 예제도 통과했습니다.
  같은 검사를 다시 실행한 수치를 합쳐 독립 검사 수로 제시하지 않습니다.
- 선택 RAG/MCP 설치본에서는 새 한국어 사례를 포함한 31개 검사, 최소 MCP 1.28.1과
  2.0.0 설치본의 실제 stdio 검사 각 18개를 통과했습니다. Presidio 경로는 6개 통과,
  설치되지 않은 경우의 오류 검사 1개 생략입니다. 소스 전체 154개 파일과 SDK 1.x 경계의
  타입 검사, 린트도 통과했습니다. 선택 분류기/ML 기능을 확장하거나 학습하지 않았습니다.
- 별도 코어 전용 설치에서 선택·네트워크 패키지 import를 금지한 상태로 API/JSON,
  파생 토큰별 Vault 왕복과 런타임 의존성 범위를 확인했습니다. 생성형 구간 검사는
  모든 처리 모드에서 BLOCK 후보의 합집합을 독립 집합 연산과 대조합니다.

이 수치는 로컬 검증 기록입니다. 배포 승인은 해당 태그의 CI 및 실제 배포 파일 명세와
구분해서 확인해야 합니다. 설치하지 않은 선택 의존성 및 sdist에 제외한 연구 자료로 인한
생략은 합격으로 계산하지 않습니다.

## 외부 합성 자료 비교

자료는 [K-PII-Bench 고정 리비전](https://huggingface.co/datasets/woohyun212/k-pii-bench/tree/844f92f7beba98fa964f957ba324017e82451701)의
Track A, CC-BY-4.0입니다. [고정 해시·라벨 대응 프로토콜](external-protocol.json)을 유지합니다.
원본 28,142건에서 SHA-256(doc_id), doc_id 순서로 서로 겹치지 않는 500건씩을 선정했습니다.
14개 대응 라벨의 strict 문자 span 점수와 STRICT/redact의 실제 출력 잔존을 함께 측정합니다.
4개 미대응 라벨은 점수 밖이며 upstream BIO 공식 평가나 실제 고객 문서 시험이 아닙니다.
1.22.18의 앞 두 표본은 배포본과 제품 코드 해시가 같은 동결 소스, 세 번째는 설치 wheel의
기존 기록이며 마지막 500건은 실제 PyPI 설치본으로 새로 실행했습니다.

0~1499는 이미 관찰한 회귀 자료입니다. 1500~1999는 이번 제품 코드 동결 후 설치 wheel로
확인했습니다. 같은 합성 코퍼스의 다른 순위일 뿐 다른 도메인·독립 평가나 과거 노출이
없었던 블라인드 자료라고 부르지 않습니다. 확인 결과를 본 뒤 제품 규칙은 변경하지 않았습니다.

| 해시 순위 (끝 제외) | 1.22.18 F1 | 1.23.0 F1 | 완전히 치환되지 않은 정답 구간 (전 → 후) |
|---|---:|---:|---:|
| 0~500 | 0.5523 | 0.5547 | 922 → 898 |
| 500~1000 | 0.5398 | 0.5428 | 985 → 961 |
| 1000~1500 | 0.5438 | 0.5522 | 957 → 918 |
| 1500~2000 | 0.5532 | 0.5578 | 977 → 951 |

같은 2,000문서의 대응 gold 7,664개에서 완전히 치환되지 않은 구간은 3,841 → 3,728개,
113개 감소했습니다. 이전에 완전히 치환되던 gold가 새로 남는 경우는 이 비교에서 0개입니다.
하지만 여전히 많은 정답 구간이 남습니다. `not_fully_replaced`에는 미탐뿐 아니라 정책상
보존과 부분 치환도 포함되므로 이 숫자를 미탐률 또는 실제 개인정보 유출률로 부르면 안 됩니다.

엄격 탐지 집계는 TP/FP/FN 4138/3320/3526 → 4203/3366/3461, micro F1 0.5473 →
0.5518입니다. 새 strict FN 25개/해소 FN 90개, 새 FP 47개/해소 FP 1개를 모두 기록합니다.
이름의 보호 범위가 늘어 gold와 경계가 달라진 경우도 strict FP/FN입니다. 점수 향상이
모든 항목의 개선이나 오탐 부재를 뜻하지 않으며 과다 마스킹은 별도 검토가 필요합니다.

### 추가 500건의 라벨별 결과

| 라벨 | TP | FP | FN | Recall |
|---|---:|---:|---:|---:|
| PERSON | 265 | 726 | 484 | 0.3538 |
| ADDRESS | 31 | 12 | 65 | 0.3229 |
| ACCOUNT | 23 | 0 | 60 | 0.2771 |
| CARD | 1 | 0 | 39 | 0.0250 |
| RRN | 145 | 0 | 66 | 0.6872 |
| PHONE | 191 | 7 | 0 | 1.0000 |
| EMAIL | 198 | 0 | 0 | 1.0000 |

이 표본의 최종 출력은 완전 치환 997, 미탐 717, 정책상 보존 215, 부분 치환 19개입니다.
식별번호의 형식/체크섬과 합성 gold의 차이가 있을 수 있으므로 이 recall을 실제 발급 번호의
성능으로 옮기지 않습니다. PHONE/EMAIL 표본 recall 1.0도 다른 문서의 무미탐 보장이 아닙니다.
자유 서술 PERSON/ADDRESS와 업무별 필수 식별자의 실제 재현율 검증은 여전히 필요합니다.

## 재현과 근거 식별

두 버전은 분리된 환경에 설치하고 같은 실행기·라벨·정책·순위를 사용합니다.
각 버전에서 다른 출력 파일을 지정하며 기존 측정을 덮어쓰지 않습니다.

```bash
python scripts/evaluate_external.py --cache /tmp/ko-pii-external \
  --download --rank-start 0 --output /tmp/ko-pii-1.23.0-ranks-0-500.json
python scripts/evaluate_external.py --cache /tmp/ko-pii-external \
  --rank-start 1500 --output /tmp/ko-pii-1.23.0-ranks-1500-2000.json
```

500, 1000도 동일 방식으로 실행합니다. 기본 실행은 네트워크나 모델을 호출하지 않습니다.
`--download`는 고정 원본 자료 다운로드의 명시적 선택입니다. 보고서에 문서 해시·좌표가
포함되므로 실제 업무 자료로 실행한 결과를 공개하기 전 검토하세요.

- 제품 `.py` 경로/내용 결합 SHA-256 (소스/wheel 동일):
  `3ddc9e823a5c78af4684b92060572215556afaa35c243074871543abfe0d5b5a`
- 0~500 선정 해시: `b6130e61877ce1519754580edddaa17dd903d735e80d57fc2474a26e32c6aabe`
- 500~1000 선정 해시: `af646556f5c486af4def3fa5e7c9f2a0b96596f1880a5039ec7dd08f0a4eb537`
- 1000~1500 선정 해시: `e8716302cc3974eb8d957cead0cadcba8556d7d780fd482c0c4527d248fe16ea`
- 1500~2000 선정 해시: `c4e370993d523726bebcdbb3ad1039214dfea9fa48a93b663e67e82cfb810d75`

업무 승인은 [도메인 평가](../docs/DOMAIN_EVALUATION.md)에서 실제 입력과 필수 라벨,
출력 잔존·오탐 허용 기준을 정한 뒤 판단해야 합니다. 합성 점수나 테스트 통과 수가
그 승인을 대신하지 않습니다.
