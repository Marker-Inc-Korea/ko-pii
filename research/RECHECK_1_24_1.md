# 1.24.1 주소 단위 회귀와 빈 이름 항목 재검사

2026-11-18, Python 3.12.3. 배포 1.24.0의 주소 경계 강화에서 생긴 실제 출력 회귀와
명시적 이름 목록의 빈 항목 문제를 수정했습니다. 모델·OCR·분류기·외부 API나 새 코어
런타임 의존성을 추가한 변경은 아닙니다.

## 재현한 문제와 수정

`주소: 서울특별시 강남구 테헤란로 152 101동근처에서 만나요.`에서:

- 1.23.1은 동 번호까지 가리고 `근처에서 만나요.`를 남겼습니다.
- 1.24.0은 기본 주소만 가리고 `101동근처에서 만나요.`를 그대로 남겼습니다.
- 1.24.1은 동 번호까지 다시 보호하고 뒤 문구를 보존합니다.

`1202호앞`, `12층로비`, 위치 명사 뒤 조사와 단위 뒤 서술형·붙여 쓴 긴 조사도 같은
경계로 검사합니다. 이름 후보의 주소 단위 판정과 문법을 공유합니다. 다만 임의의 모든
한국어 단어를 허용하지 않으며 `3호선`, `101동작`, `101동내역`, `12층로비스트`를
동호수 접미사로 자르지 않는 검사는 유지합니다. 밑줄 강조도 주소 바깥에 보존합니다.

`성명: N/A, 박보라`나 `성명: 김다은, None, 박보라`에서는 ASCII 빈 항목이 목록 문맥을
끊어 다음 이름을 놓쳤습니다. 알려진 빈 표시 `N/A`, `N.A.`, `NA`, `NULL`, `None`의
독립 항목만 처리하며 값 자체는 가리지 않습니다. 일반 단어·URL 속 조각이나 다른
줄/셀로 문맥을 전파하지 않습니다. 모든 로마자 이름을 새로 탐지하는 기능은 아닙니다.

이름/주소의 [지원 문법과 출력 범위](../docs/SCOPED_RULES_AND_TRACE.md)를 참고하세요.

## 검증 범위

- 같은 공개 처리 경계 검사 334개에서 1.24.0 설치 wheel은 155개 실패/179개 통과,
  새 구현은 모두 통과했습니다. 문법·Unicode·좌표·정책 조합 수이며 독립 결함 수나
  실제 업무 정확도가 아닙니다.
- 소스 전체 4,193개 통과/15개 생략, 별도 설치 wheel 4,178개 통과/30개 생략입니다.
  선택 의존성 생략은 통과에 합산하지 않습니다. NFC/NFD 생성형 검사는 알려진 문법의
  원문 범위·뒤 문장 보존을 독립 기대값과 비교합니다.
- 설치 wheel의 RAG/MCP 33개, 최소 MCP 1.28.1/2.0.0의 실제 stdio 각 19개,
  Presidio 규칙 연동 6개 통과/환경 반대 조건 1개 생략입니다. README의 Python·
  텍스트 CLI·구조화 CLI 예제도 통과했습니다.
- 린트와 전체 156개 소스의 타입 검사를 선택 MCP SDK 설치/미설치 환경에서 통과했습니다.
  기존 CPU 확장 가드를 유지하며 ASCII 빈 항목이 많은 이름 목록도 함께 검사합니다.
- 소스와 설치 wheel의 제품 `.py` 156개를 패키지 상대 POSIX 경로 순으로
  `경로 + NUL + 파일 내용 + NUL`로 결합한 SHA-256이 일치합니다:
  `415cb705f3594c28edab8575d6be84c366f38de3a3c2ca922511cc18d144824e`.
  외부 비교 후 제품 코드는 변경하지 않았습니다.

## 기존 외부 합성 자료와의 비교

[고정 프로토콜](external-protocol.json)의 K-PII-Bench Track A, CC-BY-4.0, 같은
리비전·해시·14개 대응 라벨·STRICT/redact를 유지했습니다. 0~2999는 이미 관찰한
회귀 자료이며 새 블라인드 평가나 고객 문서 검증이 아닙니다.

3,000건의 문서·라벨·좌표별 비교에서 새/해소 strict FN·FP와 새/해소 출력 잔존은
각 0개입니다. 각 표본의 F1과 출력 집계는 [1.24.0 기록](RECHECK_1_24_0.md)과
같습니다. gold 11,522개 중 완전히 치환되지 않은 구간도 두 버전 모두 5,512개입니다.
정책상 보존·부분 치환이 포함되므로 유출률로 해석하지 않습니다. 이번 경계 수정으로
일반 자유 문장의 PERSON/ADDRESS 정확도가 개선됐다는 주장을 하지 않습니다.

```bash
python scripts/evaluate_external.py --cache /tmp/ko-pii-external \
  --rank-start 0 --output /tmp/ko-pii-1.24.1-ranks-0.json
```

500/1000/1500/2000/2500도 같은 방식입니다. 최초 다운로드가 필요할 때만 `--download`를
명시하며 기존 결과는 덮어쓰지 않습니다. 두 버전의 환경과 출력 경로를 분리합니다.

기존 Vault 형식·API·모드는 유지하지만 복구한 주소 범위와 새 이름 때문에 탐지 수·
토큰 순서·Vault에 저장되는 원문 구간은 달라질 수 있습니다. 업무별 필수 라벨의 미탐과
최종 출력의 잔존/과다 마스킹, 문서 추출 범위와 복원 권한은 실제 자료로 계속 검증해야
합니다. 이 기록만으로 사업 적용 완료나 법적 익명성을 승인하지 않습니다.
