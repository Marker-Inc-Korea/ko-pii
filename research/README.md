# 연구 자료와 제품 검증의 경계

현재 제품은 `src/ko_pii`이며, 일반 사용에 이 디렉터리나 외부 평가 데이터를 받을 필요가 없습니다.

## 고정 외부 평가

[2026-10-26 측정 결과와 해석](EXTERNAL_EVALUATION_20261026.md)을 먼저 확인하세요.
기존 배포 1.22.0의 첫 기록에서 micro F1 0.5513이 측정됐으며, 당시 정비 릴리스는
그 측정에 맞춰 룰을 수정하지 않았습니다.
[1.22.6 여권 형식 수정 후 재검사](EXTERNAL_EVALUATION_20261027.md)에서도 같은 집계가
나왔습니다. 공식 번호 형식의 오류 수정과 외부 평가 성능 개선은 구분합니다.
[실제 PyPI 1.22.14 재검사](RECHECK_1_22_14.md)는 같은 표본에서 F1 0.5542와
완전히 치환되지 않은 934개 gold 구간을 기록합니다. 파일 추출 결함 수정과 별개로
실제 업무의 탐지·출력 품질 검증은 아직 필요합니다.
[1.22.18 이름 필드·금융 경계 수정 후 비교](RECHECK_1_22_18.md)에는 기존/추가
회귀 표본과 구현 동결 후 확인한 별도 500건의 결과를 나눠 기록합니다. 기존 표본의
오류 양상을 점검한 개발 과정이므로 새 블라인드 평가로 주장하지 않습니다.
[1.23.0 한국어 기록 경계·겹침 치환 비교](RECHECK_1_23_0.md)는 같은 2,000건에서
출력 잔존 감소와 새 오탐을 함께 기록합니다. 일반 문장 이름·주소의 낮은 재현율과
실제 업무 검증이 남아 있다는 판단은 유지합니다.
[1.23.1 금융 필드·정규식 비용 재검사](RECHECK_1_23_1.md)는 계좌 탐지 보완과
긴 공백/다중 계좌 비용을 다룹니다. 2,500건의 합성 비교에서 달라진 라벨은 ACCOUNT이며
카드 경계 수정의 일반 탐지율 개선으로 확대 해석하지 않습니다.
[1.24.0 이름 목록·상세주소·조밀한 문서 비용 재검사](RECHECK_1_24_0.md)는 공개 처리
경계와 반복 구간 조회를 보완합니다. 외부 합성 3,000건의 탐지/출력 잔존 결과는
1.23.1과 같으며 일반 문장 NER 성능 개선으로 주장하지 않습니다.
[1.24.1 주소 단위 회귀·빈 이름 항목 재검사](RECHECK_1_24_1.md)는 1.24.0에서
동호수가 다시 남던 위치 표현과 빈 항목 뒤의 이름 누락을 수정합니다. 같은 외부 회귀
자료의 결과는 유지하며 일반 업무의 정확도 보증으로 확대하지 않습니다.
[1.25.0 긴 이름·영문·한자 필드 재검사](RECHECK_1_25_0.md)는 사람 전용 필드와
같은 문서의 반복 표기를 보완합니다. 외부 회귀의 출력 잔존은 같지만 두 이름에서 조사까지
가려 strict span 점수가 소폭 낮아지는 효과도 함께 기록합니다.
[1.26.0 양식 경계·생년월일·Unicode 표 헤더 재검사](RECHECK_1_26_0.md)는 실제 원문
잔존이 재현된 양식/표 입력과 기존 별칭의 호환성을 검사합니다. 외부 자유 텍스트 회귀
결과는 같지만 그 평가만으로 표 처리나 실제 고객 문서 품질을 증명하지는 않습니다.
[1.26.1 평가 입력·출력 보고서 경계 재검사](RECHECK_1_26_1.md)는 직접 Python 입력과
모순된 출력 상태·기준 JSON을 거부하는 패치입니다. 기존 500건의 점수·출력 결과는 같으며
정확도 향상이나 고객 업무의 도입 승인으로 주장하지 않습니다.
[1.27.0 HTML 검토 기록 재검사](RECHECK_1_27_0.md)는 반복 값의 위치별 판정 유실과
다른 문서의 원문/결과를 섞던 문제를 수정합니다. 새로운 피드백 계약과 실제 브라우저
동작을 확인하며 탐지율 향상이나 업무 승인 기능으로 해석하지 않습니다.

[프로토콜](external-protocol.json)은 외부 작성자가 공개한 K-PII-Bench의 고정 리비전에서
500개 문서를 결과와 무관하게 SHA-256(doc_id) 순서로 선정합니다.
원본 파일 해시·크기·전체 문서 수도 확인합니다. 데이터는 CC-BY-4.0으로 공개된 합성 자료이며
upstream 저작자는 링크된 데이터 카드와 라이선스를 참고하세요.

현재 코어에 사용자 규칙이나 모델을 추가하지 않고 STRICT/redact로 실행합니다.
14개 대응 라벨의 엄격한 문자 span 점수, 라벨별·도메인별 결과, 실제 출력의 잔존 상태를
함께 기록합니다. 나머지 4개 upstream 라벨은 미지원으로 집계합니다.
KR_LOCATION과 ADDRESS의 의미 범위도 완전히 같지 않습니다.
upstream의 BIO 공식 점수나 실문서 검증으로 부르지 않습니다.

```bash
python scripts/evaluate_external.py --cache /tmp/ko-pii-external --output /tmp/ko-pii-external-report.json --download
```

최초 다운로드는 약 143 MB입니다. 그 뒤에는 `--download` 없이 동일 캐시를 사용할 수 있습니다.
기존 결과는 덮어쓰지 않습니다. 외부 코드를 실행하거나 모델을 받지 않으며 일반 CI에서는
다운로드하지 않습니다. `--rank-start 500` 또는 `--rank-start 1000`으로 같은 해시 순서의
다른 500건을 재현할 수 있습니다. 기본 0은 기존 표본과 같습니다. 실행 결과에 순위를
기록하며, 순위가 다르면 다른 평가 입력입니다. 반복/검토한 표본은 회귀 자료로 취급하고,
서로 겹치지 않는다는 이유만으로 블라인드 평가나 과거 노출 부재를 주장하지 않습니다.

## 역사적 자료

[catalog.json](catalog.json)은 Git에 추적된 `data/` 파일의 SHA-256·크기·출처·라이선스
확인 상태와 구문 검사 상태를 기록합니다. `python scripts/audit_research.py`로 확인합니다.
변경을 조용히 무시하지 않고 목록과 다르면 실패합니다.

- `legacy-parseable`: 구문 검사를 통과했을 뿐, 의존성·절대 경로·실험 결과까지 검증한 것은 아닙니다.
- `blocked`: 현재 실행할 수 없는 파일입니다. `data/build_eval_corpus.py`는 한국어 문자열과
  인용부호가 손상돼 있습니다. 원본을 추측 복원해 기존 gold라고 주장하지 않습니다.
- `historical-data`: 과거 입력·결과이며 최신 성능 주장의 근거가 아닙니다.

기존 경로와 파일은 보존했습니다. 과거 BENCHMARK/EVALUATION_REPORT/HYBRID_NER 및
발표 자료는 다른 데이터·라벨 정책·매처를 썼을 수 있어 현재 strict-span 점수와
직접 비교하면 안 됩니다. 옛 README는 v1.22.0 태그로 보존합니다.

## 데이터 권리

코드의 MIT 라이선스가 외부 데이터까지 포괄하지 않습니다.
KDPII는 [원 출처·CC-BY-4.0 고지](https://github.com/Marker-Inc-Korea/ko-pii/blob/main/data/kdpii/README.md)가 있으며,
KLUE와 AI Hub 파생 자료는 각각 원 배포처의 조건을 별도 확인해야 합니다.
특히 과거 AI Hub 파생 파일의 재배포 권한은 이번 인벤토리로 확정하지 못했습니다.
해당 파일을 새 데이터 제품으로 재배포하거나 사용 허가가 확인됐다고 표시하지 않습니다.
`data/` 전체는 wheel 및 sdist에 포함하지 않습니다.

자료를 새로 추가할 때 출처 URL, 리비전, 라이선스, 변경 사항과 해시를 함께 기록하세요.
실제 개인정보나 고객 문서는 공개 저장소에 넣지 마세요.
